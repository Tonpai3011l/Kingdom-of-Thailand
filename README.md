# 🇹🇭 Kingdom of Thailand

บอท Discord จำลองชีวิตประชาชนในประเทศไทย พร้อมระบบเศรษฐกิจเชิงลึก (ธนาคาร/สลาก/หุ้น), การเมือง, และการท่องเที่ยว 77 จังหวัด

---

## 🌟 ฟีเจอร์หลัก (Features)

### 💰 1. ระบบเศรษฐกิจ & การเงิน (Economy & Banking)
จำลองระบบการเงินเสมือนจริงที่ซับซ้อนและมั่นคง
- **Wallet & Personal Bank**: แยกเงินสดและเงินฝากส่วนตัว (`/balance`)
- **Central Bank (ธนาคารกลาง)**: ระบบงบประมาณแผ่นดิน จัดการโดยรัฐบาล ใช้สำหรับจ่ายดอกเบี้ยและบริหารโครงการต่างๆ
- **Merchant Banks (ธนาคารพาณิชย์)**: ระบบธนาคารแยกย่อย (เช่น MinBank) ที่รองรับการฝากเงินแบบมี **ดอกเบี้ยอัตโนมัติ** ทุก 30 นาที (7 วันขึ้นไป)
- **Financial Logging**: บันทึกทุกธุรกรรม (โอน/ฝาก/ถอน/หุ้น/หวย) ลงในช่อง Log กลางอัตโนมัติ เพื่อความโปร่งใส

### 🎰 2. สลากกินแบ่งรัฐบาล (Lottery System)
ระบบซื้อขายสลากที่ทันสมัยและลุ้นระทึก
- **Dashboard**: บอร์ดซื้อขายถาวรที่อัปเดตสถานะแบบ Real-time
- **Purchase Menu**: เลือกซื้อเลขท้าย 2 ตัว หรือ 3 ตัว (ราคาใบละ 80 บาท)
- **Automatic/Manual Draw**: สลับโหมดการออกรางวัลได้ทั้งแบบสุ่มและแอดมินระบุเลขเอง
- **Winning Check**: ตรวจรางวัลและรับเงินโอนเข้าธนาคารอัตโนมัติ พร้อมรองรับการตรวจสลากจำนวนมาก (สรุปยอดให้อ่านง่าย)

### 📈 3. ตลาดหุ้น & คริปโต (Stock Market)
จำลองการเทรดสินทรัพย์แบบ P2P ระหว่างผู้เล่นและเจ้าของหุ้น
- **Interactive Board**: กราฟราคาและรายการหุ้นที่โต้ตอบได้ผ่าน UI
- **Portfolio**: ตรวจสอบสินทรัพย์และมูลค่ารวมที่ถือครองอยู่ได้ตลอดเวลา
- **Ownership**: ผู้เล่นสามารถสร้างหุ้นของตัวเองและรับเงินลงทุนจากผู้เล่นอื่นได้

### 🗺️ 4. ท่องเที่ยวทั่วไทย (Travel 77 Provinces)
ระบบจำลองการเดินทางและเช็คอินจังหวัดต่างๆ ครบทั้ง 77 จังหวัด
- **Travel & Vehicles**: เดินทางด้วยพาหนะที่หลากหลาย พร้อมระบบ Cooldown
- **Abroad Feature**: ระบบไปต่างประเทศที่ตรวจสอบข้อมูลจริงและซิงค์ Role อัตโนมัติ
- **Population Dashboard**: ตารางสรุปประชากรในแต่ละจังหวัดแบบ Real-time

## 👮 สำหรับแอดมิน (Admin & Government)

### 🏛️ Politics & Central Bank
- `/set_budget [amount]`: ตั้งงบประมาณคงเหลือให้ธนาคารกลาง
- `/view_budget`: ดูสถานะงบประมาณปัจจุบัน
- `/setup_centralbank`: สร้างบอร์ดบริหารธนาคารกลาง

### 🏦 Bank Management
- `/setup_minbank`: สร้างจุดบริการธนาคารพาณิชย์ (ฝาก/ถอน/กู้)
- `/set_interest [percent]`: ตั้งอัตราดอกเบี้ยราย 7 วัน

### 🎰 Lottery Admin
- `/setup_lottery`: สร้างบอร์ดขายสลาก
- `/lottery_status`: เปิด/ปิด การรับซื้อสลาก
- `/draw_lottery`: สุ่มออกรางวัลและปิดงวดทันที
- `/clear_lottery`: ล้างข้อมูลสลากเพื่อเริ่มงวดใหม่

## 🛠️ โครงสร้างไฟล์ (Project Structure)
- `main.py`: จุดเริ่มต้นการรันบอทและลงทะเบียน View ถาวร
- `cogs/`:
  - `bank.py`: ธนาคารกลาง, ธนาคารพาณิชย์, และระบบดอกเบี้ย
  - `lottery.py`: ระบบสลากกินแบ่งแบบครบวงจร
  - `economy.py`: ระบบพื้นฐานกระเป๋าเงินและ Log ธุรกรรม
  - `crypto.py`: ระบบเทรดหุ้นและคริปโต
  - `thailand.py`: ระบบท่องเที่ยว 77 จังหวัด
- `json/`: ฐานข้อมูลไฟล์ JSON ที่ใช้เก็บยอดเงิน, สลาก, และข้อมูลหุ้น

## 🚀 การติดตั้ง (Installation)
1. ติดตั้ง Library: `pip install -r requirements.txt`
2. ตั้งค่าไฟล์ `.env`: ใส่ `DISCORD_TOKEN` และ `VERIFIED_ROLE_ID`
3. หากใช้ MongoDB ให้ตั้งค่า `MONGODB_URI` และตั้งค่า `MONGODB_DATABASE` ได้ (ค่าเริ่มต้นคือ `kingdom_of_thailand`)
4. รันบอท: `python main.py`

บน Render ให้ใช้คำสั่งเริ่มต้น `python main.py` และตั้งค่า `DISCORD_TOKEN`, `MONGODB_URI` และ `MONGODB_DATABASE` ใน Environment Variables ระบบจะเปิด health endpoint ที่ `/health` บนพอร์ตจากตัวแปร `PORT` โดยอัตโนมัติ ส่วนข้อมูล runtime ใน `json/` ยังคงถูกใช้งานในเครื่อง/instance แต่ถูก ignore ไม่ให้ Git ติดตามไฟล์
